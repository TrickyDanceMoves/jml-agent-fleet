      Quick Reference
      
    

    


      

        
JML Workflow

        

          
Joiner Creates account, sets attributes

          
Enroller Licenses, groups, device inventory

          
Mover Role / department / access changes

          
Leaver Soft → Hard offboarding

        

      


      

        
Required Fields

        

          
JoinerFirst name, last name, department, job title, country (2-letter)

          
EnrollerUPN only

          
MoverUPN + at least one change

          
LeaverUPN + ticket ref (e.g. INC-1234)

        

      


      

        
Leaver Stages

        

          

            Soft
            Disables account, revokes all sessions. Reversible.
          

          

            Hard
            Removes licenses and group memberships. Not auto-reversible.
          

        

      


      

        
Execution Modes

        

          

            WhatIf
            Full logic, zero directory changes. Use to preview.
          

          

            Live
            Real changes execute immediately against the tenant.
          

        

      


      

        
Policies

        

          
Freeze No changes on Saturday or Sunday

          
Dual approval Leaver Soft requires second operator

          
Ticket ref Required for Leavers, recommended for Movers

          
UPN format firstname.lastname@contoso.onmicrosoft.com
