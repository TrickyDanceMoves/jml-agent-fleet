                  Setup guide — hooking up a new tenant
                  

                    
1
Create app registrations in the target Entra tenant (one per agent). Use the ⚡ Setup Wizard above to automate this step.

                    
2
Grant Graph API permissions and admin-consent them (see Certs tab for the permissions matrix).

                    
3
Upload certificates (or store secrets) and update each agent's config.json with CertThumbprint or EncryptedSecret.

                    
4
Save Tenant ID + Client IDs above — the values will be written to all 8 agent configs on save.
