Hooking up a new tenant

                  
1. Create app registrations in the target Entra tenant (one per agent). Use ~/.claude/agents/provisioner/ scripts to automate.

                  
2. Grant Graph API permissions and admin-consent them (see Certs tab for the matrix).

                  
3. Upload certificates (or store secrets) and update each agent's config.json with CertThumbprint or EncryptedSecret.

                  
4. Save Tenant ID + Client IDs here — the values above will be written to all 8 agent configs.

Quick Reference

        
      

      

        
Color legend

        

          Cyan · primary action, info, joiner, waiting state, audit links
          Emerald · success, healthy, ok, completed
          Amber · warning, partial outcome, rotation/expiry soon, enroller
          Coral · critical, failed, live mode active, leaver, hard-stage
          Violet · Safe mode, mover, identity protection
          Muted · idle, standby, disabled, dim metadata
        


        
Status meters

        

          active · streaming live work
          waiting · pending input / token
          idle · ready, last run recently
          standby · disabled by policy until needed
          degraded · partial / failure detected
        


        
Severity

        

          CRITICAL page on-call ·
          WARNING investigate within day ·
          INFO informational only
        


        
Modes

        
 Safe Mode previews — no changes commit.  LIVE · Committing actions modify the tenant. The pill in the topbar always reflects current state.


        
Approver Agent

        
Describe the change in natural language. Type / in the input to see slash commands. The agent runs risk scoring before any Live submit and gates on dual-approval where required.


        
Hash chain

        
Every operation is signed and chained. Verify with Verify-AuditLog.ps1. The Audit Log tab shows the current chain head and Merkle proof.


        
Navigation

        
Ctrl+1…Ctrl+9 switch tabs · Ctrl+, opens Settings · Esc closes overlays.
